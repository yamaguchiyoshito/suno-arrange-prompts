```text
Create a 94 BPM vocal dream-pop track around one original eight-bar, four-note vocal motif. Number pitch classes C=0 through B=11. Choose one pitch class from each pair {1,5}, {2,10}, {4,8}, and {7,11}; use none of the fixed classes {0,3,6,9}. In section A, sing the motif unchanged. For B, replace every pitch class x with 5x mod 12 while retaining its octave number. For C, apply the map again; because 5x applied twice returns x mod 12, C must restore the exact registered notes of A. Keep syllables, durations, rests, phrasing, dynamics, chord voicing, bass, soft drums, chorus guitar, pad, and mix unchanged across A, B, and C. Repeat A-B-C once, then end on the restored motif without a coda. Use wholly original harmony, melody, lyrics, recordings, and sounds; do not imitate any identifiable song, riff, arrangement, or vocal likeness.
```
