```text
Create instrumental minimal techno at 118 BPM from an original four-bar loop of dry kick, rimshot, mono synth bass, and one short noise stab. Keep four rimshots at fixed positions and place exactly one distinct bass attack within the eighth note after each rimshot. In odd-numbered sections, treat each rimshot as an enemy trigger: silence only that following bass note. In even-numbered sections, treat it as a friend: retain that bass note and add one brief copy exactly one octave above it. Run six eight-bar sections in strict order: enemy, friend, enemy, friend, enemy, friend. Never move the rimshots or alter the underlying bass sequence. End by cutting the last added octave note short. Avoid fills, melodies, pads, breakdowns, tempo changes, unrelated automation, and simultaneous enemy/friend actions. Use only original material; do not imitate or reuse any existing melody, lyric, signature groove, recording, or sample.
```
