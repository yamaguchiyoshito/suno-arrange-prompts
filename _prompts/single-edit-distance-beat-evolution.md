Build an 88 BPM rap track from one original two-bar beat containing exactly twelve events across drums, bass, and sampler. Present it unchanged for eight bars. Create eight subsequent eight-bar sections, each differing from the immediately previous loop by exactly one edit: insert one event, delete one event, substitute one timbre, move one onset, then apply the inverse move, inverse substitution, inverse deletion, and inverse insertion in that order. An edit may affect only one event; all other onsets, pitches, durations, velocities, and sounds must remain identical. The final section must therefore equal the opening loop exactly. Keep the rap clear and leave one beat of silence at every edit boundary. Do not add transitions, fills, risers, or ad-libs at those boundaries. Use only original performances, melodies, lyrics, samples, and recordings created for this piece. Do not imitate the source artist's melody, lyrics, vocal flow, signature rhythm, sound design, or recording.
