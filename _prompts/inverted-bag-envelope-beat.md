```text
Create an instrumental abstract hip-hop beat using MASS-HOLE's “plasticbag” only as a high-level point of departure. Record an original two-bar plastic-bag crumple, extract its normalized amplitude envelope, and keep the recording itself inaudible. Apply that envelope to one sustained electric-piano chord. On odd two-bar passes, map envelope 0 to -18 dB and 1 to 0 dB, so louder crumples open the chord. On even passes invert the mapping: 0 becomes 0 dB and 1 becomes -18 dB, so the same crumples close it. Alternate normal and inverted maps eight times without changing the envelope timing, chord, or threshold. Use no hi-hat; a fixed kick and rim pattern must ignore the bag contour. Finish on an inverted pass and cut before the normal map can return. Use original material, melodies, lyrics, and recordings only; never imitate MASS-HOLE or the source track.
```
