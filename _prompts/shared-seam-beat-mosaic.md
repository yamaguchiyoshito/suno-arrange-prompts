```text
Create instrumental abstract hip-hop at 92 BPM from four self-contained cells lasting 7, 9, 11, and 13 quarter-note pulses. Give each cell a distinct original electric-piano fragment, muted synth-bass answer, and dry machine-drum pattern. End every cell with the same snare accent; that single accent must also count as the first hit of the following cell. Never duplicate the seam hit or insert a reset beat. Play the order 7–9–11–13, then rotate the starting cell on each pass: 9–11–13–7, 11–13–7–9, and 13–7–9–11. Keep each cell internally unchanged so arrangement comes only from reordered unequal lengths. Cut immediately after the final shared snare. Avoid vocals, swing correction, fills, risers, transitions, and borrowed samples. Use only newly created material; do not reuse any existing melody, lyric, signature riff, recording, or sample.
```
