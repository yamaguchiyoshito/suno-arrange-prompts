```text
Compose instrumental chamber pop from a new seven-note violin phrase containing clear rests. Duplicate it into three string voices offset by zero, one, and two sixteenth notes. Keep all pitch, accent, and rest data identical after the offsets; never resynchronize the voices.

Add rubber-bridge electric guitar only at grid positions where all three string voices are resting. Program a kick, rim, or clipped hat only on those same guitar positions; if even one violin sounds, guitar and drums must remain silent. Change harmony by transposing the entire three-voice process together every sixteen bars. Near the end, remove one violin copy, causing new eligible gaps, then stop before exploiting all of them. Use wholly original musical material; never copy an existing melody, signature violin figure, guitar tone, drum pattern, recording, or sample.
```
