```text
Write chamber folk for lead voice, soft piano, and a small string group. Choose one diatonic scale and keep every pitch inside it except the first sounded note of each eight-bar block.

Rotate responsibility for that outlier in a fixed order: voice, piano, strings, then repeat. Each outlier must sit a different chromatic interval outside the scale; never reuse the same offset. Immediately after it, all parts return to the scale while harmony, rhythm, and dynamics remain stable. Leave two beats of space before each new block so the single foreign note is exposed. In the final block, imply an outlier with silence instead of playing it, and close diatonically. Create wholly original music and lyrics; do not copy any existing melody, lyric, harmonic signature, instrumental phrase, recording, or sample.
```
