```text
Create an instrumental electronic suite at 110 BPM from five original four-bar cells using drum machine, sampler, bass, and clipped electric guitar. Make one paired re-form for each cell, changing exactly one axis. Pair A changes rhythm while pitch, timbre, stereo position, and event order stay fixed. Pair B changes pitch only. Pair C changes timbre only. Pair D changes stereo position only. Pair E changes event order only. Present A through E, then their re-forms A' through E', using hard cuts and equal section lengths. Never combine two transformations in one re-form; keep tempo, total event count, average level, and register limits constant. Close by alternating each original with its partner for one bar each: A/A', B/B', C/C', D/D', E/E'. Avoid transitions, fills, solos, added ambience, and global build. Use entirely original material; do not imitate or reuse any existing melody, lyric, signature sound, recording, or sample.
```
