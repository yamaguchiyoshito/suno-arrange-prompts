Create an instrumental dub miniature using 16FLIP's “Poolside Dub” only as a high-level structural reference. Start with one newly recorded, center-panned rim-like strike repeating every half note. Build fixed reflections in four eight-bar stages: dry only; add a 24 ms copy hard left; add a 48 ms copy hard right; add a 96 ms copy at center. Each successive copy must be exactly 3 dB quieter than the preceding event, with zero feedback and no tempo sync. In a fifth stage mute the dry strike while all three reflections continue from an inaudible trigger, making the reflected rhythm survive without its source. Bass and a soft kick stay mono and unchanged. Do not add reverb, modulation, fills, or further taps. End by muting triggers after beat 3 and letting the last 96 ms copy arrive alone. Use original material, melodies, lyrics, and recordings only; never imitate 16FLIP or the source track.
