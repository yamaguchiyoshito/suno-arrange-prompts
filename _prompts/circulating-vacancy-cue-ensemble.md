```text
Create an instrumental process ensemble at 104 BPM with drums, bass, clipped guitar, and electric piano in that circular turn order. Establish a shared four-bar eighth-note grid where no two players strike the same slot and exactly one slot is globally empty. On each repeat, only the next player acts: move one of that player's existing events into the global vacancy. Its former slot becomes the new global vacancy passed to the following player. Preserve every player's note count, pitch set, timbre, register, and dynamics; change only one event position per repeat. Run eight strict moves, then repeat state eight twice. Never add, delete, duplicate, or collide events. Avoid solos, fills, chord changes, mute-and-return, crescendos, and random variation. Use wholly original material; do not imitate or reuse any existing melody, lyric, signature groove, recording, or sample.
```
