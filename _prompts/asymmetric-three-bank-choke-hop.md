```text
Create an 89 BPM instrumental hip-hop track with three banks of original one-shots named T, H, and C. Program asymmetric one-way choking: a T hit cuts any sounding H but not C; H cuts C but not T; C cuts T but not H. Reverse-direction attacks must leave the previous sample ringing. Use the same twelve trigger positions for eight cycles, changing only which bank occupies each position so the unequal truncations reshape the groove. Keep drums dry and outside the choke network. Use self-created samples and composition only; do not borrow or imitate any existing record.
```
