Create bright vocal neo-soul at 96 BPM. Across eight consecutive eighth-note slots, repeat the cyclic binary sequence 00010111 forever: 0 means one tight closed hi-hat and 1 means one short open hi-hat. Treat the sequence as circular, so its eight overlapping three-slot windows must contain each binary triplet exactly once: 000, 001, 010, 101, 011, 111, 110, and 100. Put one soft clap only at the start of each eight-slot cycle so the cycle can be audited.

Build an original syncopated bass-guitar line, clipped clean guitar, warm chords, and relaxed rap-sung hook around it, but never alter, rotate, fill, mute, or double the hat sequence. Let arrangement changes come from harmony and vocal layers while the binary clock remains exposed. Use wholly original melody, harmony, lyrics, performances, recordings, and sounds.
