```text
Create original vocal experimental pop at 98 BPM with drums, bass guitar, electric keys, and one lead voice. Fix one eight-bar performance and repeat it four times. In block one, set L/R correlation to +1.0 for drums, +0.3 for bass, and -0.3 for keys. Every eight bars, rotate these three values forward so each instrumental bus occupies every correlation state once; block four restores the opening assignment. Keep the lead voice mono at +1.0 throughout. Gain-match every state and preserve notes, timing, dynamics, tone, effects, and panorama center; change only inter-channel correlation. Add no doubles, fills, transitions, or width automation inside a block. End in the restored state on a short unison cutoff. Use wholly original music and lyrics; do not reuse any existing melody, lyric, signature riff, recording, sample, or vocal likeness, and do not imitate the source artists.
```
